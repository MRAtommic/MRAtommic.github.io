## ✨ Features (ฟีเจอร์หลัก)

*   **Responsive Design:** รองรับการแสดงผลทั้งบน Desktop, Tablet และ Mobile
*   **Interactive UI:** เอฟเฟกต์เมาส์ (Cursor Glow), พาร์ติเคิลพื้นหลัง (Particles.js) และการเคลื่อนไหวที่นุ่มนวล
*   **Glassmorphism:** ดีไซน์สไตล์กระจกเงาที่ดูทันสมัย
*   **Fast Performance:** โหลดไวและทำงานลื่นไหลด้วย Vite

## 🚀 Getting Started (การรันโปรเจกต์)

หากต้องการรันโปรเจกต์นี้ในเครื่องของคุณ:

1.  **Clone Repository**
    ```bash
    git clone https://github.com/MRAtommic/MRAtommic.github.io.git
    cd MRAtommic.github.io
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```
